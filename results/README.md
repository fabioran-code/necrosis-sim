# Dossier results/ — placeholders

Ce dossier contient des fichiers placeholders. Pour générer les vrais résultats :

1. Active l'environnement virtuel Python :
   python3 -m venv venv
   source venv/bin/activate
2. Installe les dépendances : pip install -r requirements.txt
3. Exécute : python scripts/run_experiment_and_save_results.py

Les fichiers générés remplaceront ces placeholders :
- metrics.json
- classification_report.txt
- confusion_matrix.png
- feature_means.png
